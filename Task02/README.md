# Задача 2, вариант 26

## Условие
Известны результаты 2-х футбольных матчей между 2-мя командами N1:M1 и N2:M2 (первый матч на поле первой команды, второй на поле второй). В следующий круг выходит команда, которая забила больше мячей, чем пропустила. Если забитых и пропущенных поровну, то проходит команда, которая забила больше на чужом поле. Определить, какая из двух команд выходит в следующий круг.

## Что сделал
Счет обоих матчей вводится как "первая команда : вторая команда". Сначала сравниваю общее количество голов за два матча. Если поровну, то сравниваю голы на чужом поле: у первой команды это N2, у второй M1. Ввод, расчет и вывод сделаны отдельными методами, вся логика в `findWinner`.

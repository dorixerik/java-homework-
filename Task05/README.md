# Задача 5, вариант 26

## Условие
Напечатать в консоли фигуру (h >= 4, h четное, w >= 3). Пример для w = 13, h = 10:
```
*-----------*
|\ \ \ \ \ \|
| \ \ \ \ \ |
|\ \ \ \ \ \|
| \ \ \ \ \ |
| / / / / / |
|/ / / / / /|
| / / / / / |
|/ / / / / /|
*-----------*
```
Строки и массивы использовать нельзя, только циклы, условия и печать.

## Что сделал
Верхнюю и нижнюю рамку печатает метод `printBorder`. Внутренние строки делятся пополам: в верхней половине рисую `\`, в нижней `/`. Символ ставится через одну позицию, а сдвиг зависит от номера строки, причем нижняя половина зеркальная к верхней. Вся фигура печатается в методе `printFigure(w, h)`.

# Задача 6, вариант 26

## Условие
ln(1 + x^3) = x^3 - x^6/2 + x^9/3 - x^12/4 + ... (R = 1).
Для введенных x, n и e посчитать:
1. сумму n слагаемых
2. сумму слагаемых, которые по модулю больше e
3. сумму слагаемых, которые по модулю больше e/10
4. значение функции через Math

Член ряда нужно выражать через предыдущий, цикл только один.

## Что сделал
Первый член ряда равен x^3, а каждый следующий получается из предыдущего так: a(n) = a(n-1) * (-x^3) * (n-1) / n. Это вынесено в метод `nextTerm`. В одном цикле считаю все три суммы сразу, а для проверки вывожу `Math.log(1 + x^3)`.

# Задача 3, вариант 26

## Условие
Есть рисунок координатной плоскости с графиками и фигурами, области покрашены в разные цвета. Нужно написать функцию `getColor(x, y)`, которая для точки возвращает цвет области, в которую она попадает.

## Что сделал
По рисунку определил фигуры:
- круг с центром (-5, 6) и радиусом 3
- парабола y = -0.5 * (x + 6)^2 + 3
- парабола y = -0.25 * x^2 + 2
- горизонтальная линия y = -4

Для каждой фигуры сделал свой класс (`Circle`, `VerticalParabola`, `HorizontalLine`) с методом проверки положения точки, цвета лежат в enum `SimpleColor`. В `getColor` по очереди проверяю, где находится точка. В `main` печатаются цвета для заранее выбранных точек из всех областей и потом можно ввести свою точку.

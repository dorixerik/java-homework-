# Задача 7, вариант 26

## Условие
Вводится массив целых чисел. Найти последнюю самую длинную подпоследовательность полностью различных (ни один элемент не равен другому) подряд идущих элементов массива. Функция должна возвращать позицию первого элемента и количество элементов.

## Что сделал
В `solution` иду по массиву "окном": правая граница двигается вперед, а если новый элемент уже есть в окне, то сдвигаю левую границу. Длину сравниваю через `>=`, поэтому в ответе остается последняя из самых длинных. Возвращаю массив из двух чисел: позиция и длина. При запуске прогоняется 12 тестов (пустой массив, один элемент, все одинаковые, все разные, отрицательные числа и т.д.), потом можно ввести свой массив.

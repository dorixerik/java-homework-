# Задача 4, вариант 26

## Условие
Найти n-ое по счету (начиная с 0) целое число, запись которого в десятичной системе является палиндромом (например 0, 7, 33, 99, 111, 121, 2332). Строки и массивы использовать нельзя.

## Что сделал
Сделал метод `reverse`, который переворачивает число через деление на 10, и `isPalindrome`, который сравнивает число с перевернутым. В `findNthPalindrome` перебираю числа с нуля и считаю палиндромы, пока не дойду до нужного номера. Например для n = 10 ответ 11, для n = 19 ответ 101.

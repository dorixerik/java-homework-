# java-homework-
По рисунку я посчитал клетки и нашёл фигуры:
линия `y = 4 * (x - 0) + 6`;
прямоугольник: x от -3 до 7, y от 0 до 8;
круг: центр (-2; 3), радиус 2.

Каждую фигуру сделал отдельным классом (`Line`, `Rectangle`, `Circle`) с методом, который проверяет, попала ли точка в фигуру. Цвета записал в `enum SimpleColor`.

В методе `getColor` два `if`:
слева от линии: в прямоугольнике — зелёный, иначе белый;
справа от линии: в прямоугольнике — оранжевый, иначе синий.

Круг на рисунке только контур и цвет не меняет, поэтому в `getColor` он не нужен.

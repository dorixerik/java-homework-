Ряд: 1 - 2x + 3x² - 4x³ + ...

Чтобы не возводить x в степень каждый раз, считаю каждый член из предыдущего: a(n) = a(n-1) * (-(n+1) / n) * x, первый член равен 1.

Методы:

sumOfN — сумма n слагаемых (цикл for);
sumWithEps — складывает, пока член по модулю больше e (цикл while); использую для e и для e/10;
exact — точное значение через Math.pow.

Если ввели неправильные x, n или e, программа просит ввести заново.

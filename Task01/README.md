# Задача 1, вариант 26

## Условие
Радиусы окружностей (от меньшей к большей) r1, r2, r3. Найти площадь заштрихованной части фигуры (рис. 2.6).

## Что сделал
Разбил фигуру на части: маленький круг, два кольца и углы квадрата вокруг большого круга (сторона квадрата 2 * r3). Диагонали и оси делят все на 8 одинаковых секторов по 45 градусов, поэтому посчитал, сколько восьмых закрашено в каждой части:
- маленький круг: 1/8
- среднее кольцо: 3/8
- большое кольцо: 1/2
- углы квадрата: 5/8

Для площади круга, кольца и углов сделал отдельные методы, итоговая площадь считается в `calcShadedArea`. Радиусы вводятся с клавиатуры.
